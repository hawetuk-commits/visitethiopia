# Visit Ethiopia

A simple, static website introducing visitors to destinations and heritage sites in Ethiopia.

## View the website

Open [`visitEthiopia/html/visitethiopia.html`](visitEthiopia/html/visitethiopia.html) in a web browser. No installation or build step is required.

## Project structure

- `visitEthiopia/html/` — website HTML pages
- `visitEthiopia/assets/css/` — stylesheets
- `visitEthiopia/assets/images/` — images used by the pages

The main page loads its stylesheet and images using relative paths, so keep the `html` and `assets` folders together when moving or hosting the project.
